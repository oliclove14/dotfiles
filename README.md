# 🌸 miku's dotfiles

> my personal linux rice for CachyOS + Hyprland

## ✦ setup
- **OS:** CachyOS
- **WM:** Hyprland
- **Terminal:** Kitty
- **Shell:** Fish
- **Bar:** AGS (end-4 dots)
- **Fetch:** Fastfetch
- **Music:** Spotify-player
- **Files:** Yazi

## ✦ install
fresh CachyOS install? one command:
```bash
git clone https://github.com/oliclove14/dotfiles && cd dotfiles && bash install.sh
```
